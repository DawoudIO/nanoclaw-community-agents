Triage issues and PRs opened or updated since your last run, across the repos
you're wired to.

**New issues** — flag likely duplicates of existing open issues; flag anything
that reads like a security report (never comment on it yourself — see
`skills/coding-ops/references/reporting-to-lead.md`); note anything missing
basic repro info.

**PR hygiene** — flag PRs with no activity in 5+ days and no blocking review
comment; flag PRs that look ready to merge but are waiting on a maintainer.

**Stale issues** — anything aging with no reply; list for the digest, do not
close.

Hand the whole thing to your lead agent as one digest — you don't post, label,
or comment on GitHub directly from this task. If nothing needs attention, one
line saying so is the whole report.
