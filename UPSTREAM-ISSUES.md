# Upstream issue tracker — candidates for nanocoai/nanoclaw

Platform behaviors observed on real installs that likely affect every
NanoClaw user, and that are **still open**. Rule: **confirm on a clean
install first** (`nanoclaw.sh`, current `main`), then file — one issue each,
include the image digest from `platform-baseline.json`, and reference
existing issue #411 where relevant. Update the Status column as testing
progresses; remove a row once it is fixed upstream rather than marking it
closed, so this stays a list of things that can still bite you.

Numbering is stable and has gaps: resolved entries are deleted, and the
remaining numbers are left alone so cross-references keep working.
